<p id="mwCA"><b id="mwCQ">Thompson sampling</b>,<sup about="#mwt4" class="mw-ref reference" id="cite_ref-ref1_1-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"ref1"}}'><a href="#cite_note-ref1-1" id="mwCg"><span class="mw-reflink-text" id="mwCw"><span class="cite-bracket" id="mwDA">[</span>1<span class="cite-bracket" id="mwDQ">]</span></span></a></sup><sup about="#mwt5" class="mw-ref reference" id="cite_ref-ref1b_2-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"ref1b"}}'><a href="#cite_note-ref1b-2" id="mwDg"><span class="mw-reflink-text" id="mwDw"><span class="cite-bracket" id="mwEA">[</span>2<span class="cite-bracket" id="mwEQ">]</span></span></a></sup><sup about="#mwt6" class="mw-ref reference" id="cite_ref-FnTTutorial_3-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"FnTTutorial"}}'><a href="#cite_note-FnTTutorial-3" id="mwEg"><span class="mw-reflink-text" id="mwEw"><span class="cite-bracket" id="mwFA">[</span>3<span class="cite-bracket" id="mwFQ">]</span></span></a></sup> named after <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/William_Rae_Thompson" title="William Rae Thompson" id="mwFg">William Rae Thompson</a>, is a <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Heuristic" title="Heuristic" id="mwFw">heuristic</a> for choosing actions that address the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Exploration–exploitation_dilemma" title="Exploration–exploitation dilemma" id="mwGA">exploration–exploitation dilemma</a> in the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Multi-armed_bandit" title="Multi-armed bandit" id="mwGQ">multi-armed bandit</a> problem. It consists of choosing the action that maximizes the expected reward with respect to a randomly drawn belief.</p>

<section data-mw-section-id="4" id="mwmw" aria-labelledby="Probability_matching"><div class="mw-heading mw-heading3"><h3 id="Probability_matching">Probability matching</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Thompson_sampling&amp;action=edit&amp;section=4" title="Edit section: Probability matching"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>

<span class="mw-empty-elt" about="#mwt52" typeof="mw:Transclusion" id="mwnA" data-mw='{"parts":[{"template":{"target":{"wt":"See also","href":"./Template:See_also"},"params":{"1":{"wt":"Probability matching"}},"i":0}}]}'><style data-mw-deduplicate="TemplateStyles:r1368532237" typeof="mw:Extension/templatestyles" about="#mwt53" data-mw='{"name":"templatestyles","attrs":{"src":"Module:Hatnote/styles.css"},"body":{"extsrc":""}}'>.mw-parser-output .hatnote{font-style:italic}.mw-parser-output div.hatnote{padding-left:1.6em;margin-bottom:0.5em}.mw-parser-output .hatnote i{font-style:normal}.mw-parser-output .hatnote+.mw-empty-elt+.hatnote{margin-top:-0.5em}@media print{body.ns-0 .mw-parser-output .hatnote{display:none!important}}</style></span><div role="note" class="hatnote navigation-not-searchable" about="#mwt52" id="mwnQ">See also: <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Probability_matching" title="Probability matching">Probability matching</a></div>

<p id="mwng"><a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Probability_matching" title="Probability matching" id="mwnw">Probability matching</a> is a decision strategy in which predictions of class membership are proportional to the class base rates. Thus, if in the training set positive examples are observed 60% of the time, and negative examples are observed 40% of the time, the observer using a probability-matching strategy will predict (for unlabeled examples) a class label of "positive" on 60% of instances, and a class label of "negative" on 40% of instances.</p>

</section><section data-mw-section-id="5" id="mwoA" aria-labelledby="Bayesian_control_rule"><div class="mw-heading mw-heading3"><h3 id="Bayesian_control_rule">Bayesian control rule</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Thompson_sampling&amp;action=edit&amp;section=5" title="Edit section: Bayesian control rule"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>

<p id="mwoQ">A generalization of Thompson sampling to arbitrary dynamical environments and causal structures, known as <b id="mwog">Bayesian control rule</b>, has been shown to be the optimal solution to the adaptive coding problem with actions and observations.<sup about="#mwt54" class="mw-ref reference" id="cite_ref-ref5_5-2" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"ref5"}}'><a href="#cite_note-ref5-5" id="mwow"><span class="mw-reflink-text" id="mwpA"><span class="cite-bracket" id="mwpQ">[</span>5<span class="cite-bracket" id="mwpg">]</span></span></a></sup> In this formulation, an agent is conceptualized as a mixture over a set of behaviours. As the agent interacts with its environment, it learns the causal properties and adopts the behaviour that minimizes the relative entropy to the behaviour with the best prediction of the environment's behaviour. If these behaviours have been chosen according to the maximum expected utility principle, then the asymptotic behaviour of the Bayesian control rule matches the asymptotic behaviour of the perfectly rational agent.</p>

</section><section data-mw-section-id="6" id="mwyA" aria-labelledby="Upper-confidence-bound_(UCB)_algorithms"><div class="mw-heading mw-heading3"><h3 id="Upper-confidence-bound_(UCB)_algorithms"><span id="Upper-confidence-bound_.28UCB.29_algorithms" typeof="mw:FallbackId"></span>Upper-confidence-bound (UCB) algorithms</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Thompson_sampling&amp;action=edit&amp;section=6" title="Edit section: Upper-confidence-bound (UCB) algorithms"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>

<p id="mwyQ">Thompson sampling and upper-confidence bound algorithms share a fundamental property that underlies many of their theoretical guarantees.  Roughly speaking, both algorithms allocate exploratory effort to actions that might be optimal and are in this sense "optimistic".  Leveraging this property, one can translate regret bounds established for UCB algorithms to <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Bayesian_regret" title="Bayesian regret" id="mwyg">Bayesian regret</a> bounds for Thompson sampling<sup about="#mwt76" class="mw-ref reference" id="cite_ref-RussoVanRoy2014_13-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"RussoVanRoy2014"}}'><a href="#cite_note-RussoVanRoy2014-13" id="mwyw"><span class="mw-reflink-text" id="mwzA"><span class="cite-bracket" id="mwzQ">[</span>13<span class="cite-bracket" id="mwzg">]</span></span></a></sup> or unify regret analysis across both these algorithms and many classes of problems.<sup about="#mwt77" class="mw-ref reference" id="cite_ref-RussoVanRoy2013_14-0" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{"name":"RussoVanRoy2013"}}'><a href="#cite_note-RussoVanRoy2013-14" id="mwzw"><span class="mw-reflink-text" id="mw0A"><span class="cite-bracket" id="mw0Q">[</span>14<span class="cite-bracket" id="mw0g">]</span></span></a></sup></p>
