# D3.2 — TS anomaly — change-point

*Section:* D — Time Series

**Description:** Detect abrupt shifts in level, variance, or trend. All D3.2 detectors (PELT, BOCPD, BinarySegmentation, CUSUM, T-squared+Q) natively model trend and are appropriate for STRUCTURAL anomalies (change in the trend/level/seasonal itself). Do NOT wrap in AnomalyPipeline contextual mode: detrending would erase the signal. Use AnomalyPipeline(..., mode="structural") or call detector directly.

**Real-life examples:**
- Price regime change
- Sensor calibration shift

### BOCPD — baseline / tier1_core

**Roles:** probabilistic
**Status:** ✓ cadw

**Purpose:** Bayesian online change-point detection with Student-t predictive likelihood (Adams & MacKay 2007). Run-length posterior plus NIG conjugate prior; score = P(change at t) = R[0], threshold 0.5. Student-t critical for heavy-tailed industrial data (SKAB: 32 percent DR at 13 percent FAR vs BOCPD-Gaussian ~0 percent DR).

**Use cases:**
- Industrial sensor changepoint
- Online regime detection

**Config:** `{'hazard_rate': 'float', 'mu0': 'float', 'kappa0': 'float', 'alpha0': 'float', 'beta0': 'float', 'burn_in': 'int'}`

**CADW:** `cadw.ml.bocpd.fit_bocpd`

**Benchmarks:**
- **[cadw_measured]** cadw_internal → recall=1.0 (n=1)
  - algorithm: `cadw.ml.bocpd.fit_bocpd` (code)
  - number: .pingis/benches/bocpd.json
  - code/paper: cadw/ml/bocpd.py
  - note: CADW-native: recall=1.0 (5/5 cp exact), median_detection_delay=0.0, fit_time=7.3s, RSS=32MB on synthetic_alternating_mean_shifts (n=20000). hazard=1/500, contamination=0.02, burn_in=20; threshold=max(percentile(1-c), 0.5) per Adams & MacKay.

## Metrics
- **auprc** (anchor, higher)
  - Change-point discrimination against imbalance.
  - *special:* WEAK anchor for changepoint — point-wise auprc ignores timing. Prefer NAB + detection_delay when both reported (SKAB).
- **nab** (diagnostic, higher)
  - NAB score (standard Numenta metric); SKAB changepoint convention.
  - *special:* Combines false-positive rate and detection delay at application profile; ground truth tolerance-window dependent.
- **detection_delay** (pareto_axis, lower)
  - Samples between true and detected changepoint.
  - *special:* Only meaningful if detection_rate is reported alongside.
- **range_f1** (diagnostic, higher)
  - Range-aware F1 with tolerance windows.
  - *special:* For changepoint, report detection_delay alongside; single ground-truth point makes range_f1 sensitive to tolerance choice.
- **point_f1** (diagnostic, higher)
  - Point-wise F1 without tolerance.
  - *special:* Strict for changepoint (single timestamp); use detection_delay as the timing-aware alternative.
- **recall** (diagnostic, higher)
  - Fraction of true change-points detected within tolerance; used by CADW cadw_measured synthetic-bench entries.
  - *special:* Tolerance-window dependent; report detection_delay alongside.

## Ensemble rules
- **[temporal_dynamics, representation, probabilistic]** → PELT + T-squared+Q + BOCPD (max_per_role=1)
  - 3 paradigms: PELT (exact batch pruning, O(n) with early pruning), T-squared+Q (PCA subspace SPC, batch), BOCPD-StudentT (Bayesian online run-length). avg change scores. v0.9.72b: 3-role ensemble after BOCPD implementation + T-squared+Q retier.
