*Section:* D — Time Series

**Description:** Detect abrupt shifts in level, variance, or trend.

**Real-life examples:**

- Sensor calibration shift

## Metrics
- **auprc** (anchor, higher)
  - Change-point discrimination against imbalance.
  - *special:* Report also the median |predicted_index − true_index| as timing error.
- **detection_delay** (pareto_axis, lower)
  - Samples between true and detected changepoint.
  - *special:* Only meaningful if detection_rate is reported alongside.

## Ensemble rules
- **[temporal_dynamics]** → PELT (max_per_role=1)
  - Single model — BinarySeg is baseline only.
