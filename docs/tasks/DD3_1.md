# D3.1 — TS anomaly — point

*Section:* D — Time Series

**Description:** Detect isolated points that deviate sharply from local behaviour.

**Real-life examples:**
- IoT sensor glitch detection
- Transaction fraud in a stream

## Benchmarks
- **UCR_Anomaly** — https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - metrics: auprc, point_adjusted_f1

## Models
### zscore — baseline / tier1_core

**Roles:** local_structure
**Status:** ✓ agent, desc

**Purpose:** Rolling-window z-score threshold; simplest detector.

**Use cases:**
- Sensor threshold alarms

**Config:** `{'window': 'int', 'threshold': 'float'}`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.41
  - algorithm: `scipy.stats.zscore` (docs)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.zscore.html
  - note: [legacy v0.9.44, migrated v0.9.50]

### IForest — baseline / tier1_core

**Roles:** nonlinear_interactions
**Status:** ✓ cadw, ✓ agent

**Purpose:** Random-split ensemble; strong on high-dim / mixed features.

**Use cases:**
- Server metric anomaly

**Config:** `{'n_estimators': 'int', 'subsample_size': 'int'}`

**CADW:** `cadw.ml.iforest.fit_isolation_forest`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.48
  - algorithm: `sklearn.ensemble.IsolationForest` (docs)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html
  - note: [legacy v0.9.44, migrated v0.9.50]

### MatrixProfile — sota / tier1_core

**Roles:** local_structure, temporal_dynamics
**Status:** ✓ cadw, ✓ agent

**Purpose:** Distance-profile of each subsequence to its nearest neighbour.

**Use cases:**
- ECG anomaly detection

**Config:** `{'window': 'int'}`

**CADW:** `cadw.ml.matrix_profile.fit_matrix_profile`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.54
  - algorithm: `STUMPY matrix profile` (docs)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://stumpy.readthedocs.io/en/latest/
  - note: [legacy v0.9.44, migrated v0.9.50]
- **[cadw_measured]** cadw_internal → fit_time_s=3.174 (n=2)
  - algorithm: `cadw.ml.matrix_profile.fit_matrix_profile` (code)
  - number: .pingis/benches/matrix_profile.json
  - code/paper: cadw/ml/matrix_profile.py
  - note: CADW-native: fit_time_s=0.6 @n=100k and 3.174 @n=1M (matrix_profile.json); NOT comparable to external LB. No std across runs.

## Metrics
- **auprc** (anchor, higher)
  - Anomaly discrimination under heavy imbalance.
  - *special:* Prefer to ROC-AUC when anomaly rate<5%; not comparable to F1.
- **point_adjusted_f1** (diagnostic, higher)
  - F1 with 1-point tolerance window (widely reported on UCR).
  - *special:* Tolerant of ±1-off detections; do not compare to raw F1.

## Ensemble rules
- **[local_structure, nonlinear_interactions]** → MatrixProfile + IForest (max_per_role=1)
  - Average z-scored anomaly scores; MP catches periodic patterns, IForest catches global outliers.
