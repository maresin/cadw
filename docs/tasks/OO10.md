# O10 — Drift detection

*Section:* O — Data Science outside ML (EDA / cleaning / feature engineering / validation)

**Description:** Detect distribution shifts between a reference batch and a current batch, per feature.

**Real-life examples:**
- Production model monitoring
- Post-deploy data-health check
- Feature drift in recommender

## Benchmarks
- **Evidently_Reference** — https://docs.evidentlyai.com/
  - metrics: psi, ks_p, chi2_p, drift_share
- **cadw_internal** — https://github.com/maresin/Cadw_framework/tree/main/.pingis/benches
  - metrics: psi, ks_p, chi2_p

## Models
### DriftStats — baseline / tier1_core

**Roles:** calibration
**Status:** ✓ cadw, ✓ agent

**Purpose:** KS, chi2, PSI per feature computed with Reduce stats. Inductive bias: independent per-feature drift; misses multivariate drift.

**Use cases:**
- Batch feature drift
- Pre-retrain check
- Production dashboard

**Config:** `{'threshold': 'float', 'n_bins': 'int'}`

**CADW:** `cadw.ml.drift.fit_drift`

**Benchmarks:**
- **[cadw_measured]** cadw_internal → psi=0.0856 (n=3)
  - algorithm: `cadw.ml.drift.fit_drift` (code)
  - number: .pingis/benches/drift.json
  - code/paper: cadw/ml/drift.py
  - note: CADW-native: psi=0.1079 @n=10k, 0.0888 @n=100k, 0.0856 @n=1M (drift.json). NOT comparable to external.
- **[cadw_measured]** cadw_internal → ks_p=0.0 (n=3)
  - algorithm: `cadw.ml.drift.fit_drift` (code)
  - number: .pingis/benches/drift.json
  - code/paper: cadw/ml/drift.py
  - note: CADW-native: ks_p=4.45e-82 @n=10k, 0.0 @n=100k and 1M (drift.json; synthetic shifted distribution). NOT comparable to external.

### EvidentlyDrift — sota / tier3_export

**Roles:** calibration, representation
**Status:** desc, export

**Purpose:** Suite of per-feature drift metrics (PSI/KS/Chi2/Wasserstein) with a reported share-of-drifted-columns. Inductive bias: univariate drift per column; aggregates to a dashboard.

**Use cases:**
- Full observability suite
- Data + target drift
- Report generation

**Config:** `{'tests': 'list'}`

**Benchmarks:**
- **[literature]** Evidently_Reference → psi=null
  - algorithm: `evidently.report.Report` (docs)
  - number: https://docs.evidentlyai.com/introduction
  - code/paper: https://github.com/evidentlyai/evidently
  - note: fetch_ok_no_number: https://docs.evidentlyai.com/introduction (Evidently docs); no cross-dataset drift-detector leaderboard published.

## Metrics
- **psi** (anchor, lower)
  - Population Stability Index between reference and current per-feature bins; <0.1 typically stable, >0.25 shifted.
  - *special:* Threshold is domain-specific; report the binning scheme.
- **ks_p** (diagnostic, lower)
  - Two-sample Kolmogorov-Smirnov p-value.
- **chi2_p** (diagnostic, lower)
  - Chi-square p-value for categorical features.
- **drift_share** (diagnostic, lower)
  - Fraction of drifted columns (Evidently convention).

## Ensemble rules
- **[calibration]** → DriftStats (max_per_role=2)
  - Use DriftStats for lightweight in-process monitoring; EvidentlyDrift for a full dashboard with data-drift and target-drift reports.
