# D3.3 — TS anomaly — shape

*Section:* D — Time Series

**Description:** Detect shape motifs that deviate from the normal repertoire.

**Real-life examples:**
- ECG morphology anomalies
- Gesture anomalies

## Benchmarks
- **UCR_Anomaly** — https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - metrics: auprc

## Models
### zscore — baseline / tier1_core

**Roles:** local_structure
**Status:** ✓ agent, desc

**Purpose:** Rolling-window z-score threshold; simplest baseline for shape-agnostic outlier detection.

**Use cases:**
- Sensor threshold alarms

**Config:** `{'window': 'int', 'threshold': 'float'}`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.32
  - algorithm: `scipy.stats.zscore` (docs)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.zscore.html
  - note: [legacy v0.9.44, migrated v0.9.50]

### MatrixProfile_discord — sota / tier1_core

**Roles:** local_structure
**Status:** ✓ cadw, ✓ agent

**Purpose:** MP discords: subsequences whose nearest-neighbour distance is largest.

**Use cases:**
- ECG anomalies

**Config:** `{'window': 'int', 'top_k': 'int'}`

**CADW:** `cadw.ml.matrix_profile.fit_matrix_profile`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.47
  - algorithm: `STUMPY matrix profile` (docs)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://stumpy.readthedocs.io/en/latest/
  - note: [legacy v0.9.44, migrated v0.9.50]

### MiniRocket_embedding — baseline / tier1_core

**Roles:** representation
**Status:** ✓ cadw, ✓ agent

**Purpose:** Random convolutional kernel projection; then outlier score in embedding space.

**Use cases:**
- ECG morphology (UCR)

**Config:** `{'num_kernels': 'int'}`

**CADW:** `cadw.ml.minirocket.fit_minirocket`

**Benchmarks:**
- **[literature]** UCR_Anomaly → auprc=0.5
  - algorithm: `MiniRocket` (paper)
  - number: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
  - code/paper: https://arxiv.org/abs/2103.01827
  - note: [legacy v0.9.44, migrated v0.9.50]

## Metrics
- **auprc** (anchor, higher)
  - Subsequence-level anomaly detection.
  - *special:* Point-level AUPRC inflates scores on shape anomalies; report window-level.
- **best_5_ranking** (diagnostic, lower)
  - Rank of top-5 detections in ground truth (UCR-style).
  - *special:* Authoritative for UCR paper comparisons; not continuous.

## Ensemble rules
- **[representation, local_structure]** → MiniRocket_embedding + MatrixProfile_discord (max_per_role=1)
  - Concatenate embeddings + MP distance into a 2D score.
