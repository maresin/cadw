# O11 — A/B testing / statistical tests

*Section:* O — Data Science outside ML (EDA / cleaning / feature engineering / validation)

**Description:** Compare two variants with correct uncertainty; decide when a difference is real.

**Real-life examples:**
- A/B test on conversion
- CUPED adjustment for pre-period covariates
- Non-parametric test on skewed revenue

## Models
### ProportionsZTest — baseline / tier1_core

**Roles:** probabilistic
**Status:** ✓ cadw, ✓ agent

**Purpose:** Two-proportion z-test on the conversion rate. Inductive bias: normal approximation to the binomial; valid when both groups have >5 successes and >5 failures.

**Use cases:**
- Conversion A/B
- Click-through difference
- Signup-funnel test

### CUPED — sota / tier1_core

**Roles:** calibration, probabilistic
**Status:** ✓ cadw, ✓ agent

**Purpose:** Deng et al. 2013 — variance reduction via a pre-period covariate; regress out its correlation with the metric. Inductive bias: linear relation between pre- and post-period; gives tighter CIs at fixed sample size.

**Use cases:**
- Pre/post A/B on revenue
- Variance reduction on CTR
- ML-platform experiments

**Config:** `{'covariate': 'string'}`

**CADW:** `cadw.ml.drift.fit_ab_test`

**Benchmarks:**

  - algorithm: `cadw.ml.drift.fit_ab_test (cuped)` (code)

  - note: CADW-native: cuped_theta=0.7978 @n=10k, 0.7999 @n=100k, 0.8 @n=1M (drift.json; synthetic covariate correlated with metric). NOT comparable to external.

## Metrics
- **p_value** (anchor, lower)
  - p-value of the two-sample test; lower means stronger evidence against the null.
  - *special:* Never compare p-values across experiments; the decision threshold is a design choice.
- **power** (diagnostic, higher)
  - Probability of detecting a true effect of the given size.
- **ci_width** (diagnostic, lower)
  - Width of the confidence interval on the effect; CUPED shrinks this.
- **cuped_theta** (diagnostic, target)
  - CUPED regression coefficient theta on the pre-period covariate.
- **t_p** (diagnostic, lower)
  - Welch t-test p-value for A/B.
- **mw_p** (diagnostic, lower)
  - Mann-Whitney U p-value for A/B.

## Ensemble rules
- **[probabilistic, calibration]** → ProportionsZTest + CUPED (max_per_role=2)
  - Use CUPED on top of ProportionsZTest when a pre-period covariate is available; drop to MannWhitneyU when the metric is heavy-tailed.
