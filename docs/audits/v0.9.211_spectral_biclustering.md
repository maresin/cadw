## §1. Implementation summary

`fit_spectral_biclustering` (cadw/ml/spectral_biclustering.py, ~360 lines)

Pipeline (sklearn parity):
1. A (r,c) dense; normalize by method:
   - `bistochastic`: iter `_scale_normalize` until tol<1e-5
   - `scale`: single `_scale_normalize`
   - `log`: log(A_clipped>=1) - row_avg - col_avg + global_avg
2. n_sv = n_components + (1 if method != 'log' else 0)
3. U, sigma, V = svd_topk(A_norm, n_sv, compute_u=True) [Pattern #1]
4. ut = U[:,1:].T; vt = V[:,1:].T (n_discard=1 for bist/scale)
5. best_ut = _fit_best_piecewise(ut, n_best, n_row_clusters)
   best_vt = _fit_best_piecewise(vt, n_best, n_col_clusters)
6. row_labels = _project_and_cluster(A, best_vt.T, n_row_clusters)
   col_labels = _project_and_cluster(A.T, best_ut.T, n_col_clusters)
7. rows_/columns_ indicator matrices (sklearn parity)

## §3. Sklearn parity

Smoke (high-contrast checkerboard 200x100):

| Method | ARI_row | ARI_col |
|---|---|---|
| bistochastic | 1.0000 | 1.0000 |
| scale | 1.0000 | 1.0000 |
| log | 1.0000 | 1.0000 |

Note: sklearn svd_method='randomized' is approximate on k>=3; CADW
uses exact svd_topk (always sorted descending). On high-contrast data
k=2, ARI=1.0 (both exact). On k>=3 (with n_components=6, n_best=3),
discrepancies are possible but algorithmically correct (exact SVD).
