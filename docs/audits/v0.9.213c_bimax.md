## §1. Implementation

`fit_bimax` (cadw/ml/bimax.py, ~330 lines):
- Materialize A (r, c) int8 binary from `X_cols > threshold`.
- Recursive divide-and-conquer (Prelic 2006 BIMAX):
  * all-1 submatrix (>= min_rows, min_cols) -> emit.
  * all-0 -> discard.
  * else: max-balance split (row/col score = min(ones, zeros)).
  * best_row wins -> split COLS by row i*; best_col wins -> split
    ROWS by col j*.
- Dedup: keep inclusion-maximal.
