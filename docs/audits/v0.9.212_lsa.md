## §2. OOC declaration

**Pattern #1 (batch-layer), axis = n (rows/docs):**

| Phase | State | Bound |
|---|---|---|
| fit_tfidf | V*f64 (idf) + V*avg_word_len (vocab) | bounded_by_domain {V: 1e5} |
| randomized SVD | V*L*f64*2 (Y, Q) + L*L*f64 (B) + 256 | (same V bound) |
| transform | O(batch * V) per batch + SpillArray (n, k) | OOC in n |

`bounded_state: true`, `n_scalability: constant`.
`bounded_by_domain {V: 1e5}` (vocab_size realistic after min_df; 
V=1e5, L~110 = 88 MB).

## §3. Sklearn parity

Smoke (n=200, vocab_size=50, k=5, q=4):

```
cadw sigma: [6.29581522 5.51230864 5.07021429 4.53613972 4.47213595]
sk sigma:   [6.29581522 5.51230864 5.07021429 4.53613972 4.47213595]
sigma max diff: 6.22e-15
Z max diff (sign-aligned): 1.14e-13
```

**Bit-identical** (better than expected — sklearn randomized on this
small data also converges to exact; q=4 sufficient).

## §4. Algorithm (Halko 2011 via Y = X^T X Omega)

For tall sparse X (n >> V), computing `Y = X^T X Omega (V, L)` is more
efficient than `Y = X Omega (n, L)`:
- State O(V*L), not O(n*L) → **OOC in n**.
- Same sigma/components (X^T X has same singular values squared).

Power iterations: q=4 default (Halko; P6b showed q=1 4e-2 error, q=4
3e-4 — stable).
