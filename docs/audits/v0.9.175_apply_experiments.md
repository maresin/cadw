## §1. Six experiments

| # | Pattern | Expected OOC? | AST-detectable? | runtime-detectable? |
|---|---|---|---|---|
| E1 | `lambda x: x * 2` (elementwise) | Yes (O(batch)) | n/a (safe) | n/a |
| E2 | `lambda row: {'a': ..., 'b': ...}` (dict return) | Yes (O(batch·dict)) | n/a (safe) | n/a |
| E3 | `lambda row: sum(...) / len(...)` (row-wise complex) | Yes (O(batch)) | n/a (safe) | n/a |
| E4 | closure `acc.append` | **No** (O(n)) | **Yes** (`ast.Attribute` + closure name) | **Yes** (tracemalloc) |
| E5 | aggregate: `lambda col: col.sum()` (df-level, not row) | Yes (O(1) output) | partially (shape change) | n/a |
| E6 | `groupby('g').apply(...)` | Yes if n_groups bounded; No if n_groups ~ n | partially | Yes |

## §2. Measurement protocol (v0.9.191)

For each E_n:

```python
peak(n=1e3) = measure_peak_traced(apply_fn, df_n=1e3)
peak(n=1e5) = measure_peak_traced(apply_fn, df_n=1e5)
ratio = peak(1e5) / peak(1e3)

# Assertions:
# E1-E3, E5, E6 (n_groups=100): ratio < 2.0  → OOC
# E4: ratio > 50  → NOT OOC, AST must catch
```

For AST detectability:

```python
import ast
tree = ast.parse(inspect.getsource(func))
# Pattern: ast.Attribute value is Name, attr in {append, add, extend},
# ctx=Load; enclosing Call; the Name is captured from closure (not
# assigned within func).
```

For runtime detectability:

```python
# apply_checked with tracemalloc, sample every 1000 rows.
# Assert E4 raises MemoryLimitExceeded at ~n/2 (baseline 10 MB).
# Assert E1-E3, E5, E6 complete without raise.
```

## §3. AST rules (draft, to be validated)

Detect:
1. `ast.Attribute` with `.append` / `.add` / `.extend` on `ast.Name` bound outside func (closure)
2. `ast.Assign` to `ast.Subscript` on closure dict
3. `ast.Call` to `np.concatenate` / `np.vstack` / `np.hstack` with closure arg
4. `ast.Global` declaration inside func

Emit `ApplySafetyWarning` with:
- pattern type
- line number in func source
- suggestions

Do **not** detect (known gaps):
- Dynamic patterns (`getattr`, `setattr`, indirect mutation)
- `np.cumsum` on full array inside func (safe if scalar return, dangerous if accumulates)
- Generators (lazy, usually safe)

---

## §4. Runtime rules (draft, to be validated)

- tracemalloc tracks **Python** allocations (closure list, dict, numpy *object* wrappers).
- numpy arrays via `malloc` → invisible to tracemalloc; use RSS sampler.
- **Combined:** every 1000 rows, sample both. If `growth > 2 * baseline` **and** `growth > 10 MB` → raise.
- **FP rate:** documented ~5-10% (false positives from legitimate per-batch caching).
- **FN rate:** undetectable patterns (`getattr` dynamic); documented.

## §6. Design decisions already made

- `apply` (default) → AST warning only, no refuse (**DEC-069**).
- `apply_checked` → runtime detection, raise on growth.
- `apply_safe` → `func(batch, mg)` signature contract.

See DEC-069 for full API rationale.
