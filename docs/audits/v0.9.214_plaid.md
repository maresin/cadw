## §1. Implementation

`fit_plaid_model` (cadw/ml/plaid_model.py, ~360 lines):
- Model: `A_ij = sum_l theta_ijl + eps_ij`, `theta_ijl = mu_l +
  alpha_il + beta_jl` for (i,j) in layer l, 0 otherwise.
- **Deterministic ALS variant** of original Bayesian MCMC (paper's
  inference; ALS is faster/simpler, faithful layer decomposition;
  documented in API).
- 4-step per-layer: (1) seed = argmax|R|, (2) expand R_l/C_l via
  mean|R| > threshold, (3) ALS fit (mu, alpha, beta) with re-centering,
  (4) residual -= theta_l.

## §5. Deterministic ALS vs Bayesian MCMC

The paper (Lazzeroni & Owen 2002) uses a Bayesian MCMC sampler for
posterior over layer parameters. CADW implements a deterministic ALS
variant:
- **Faithful**: additive layer decomposition `mu + alpha + beta`,
  residual update, seed selection by |R|.
- **Different inference**: no posterior, no uncertainty; point estimate
  via alternating LS.
- **Faster**: MCMC would be 100-1000x slower (needs posterior draws).
- **Documented** in every API call (fit_plaid_model docstring).

Future (v0.9.215+): optional Bayesian variant if uncertainty quantification
needed. Current honest `status: verified` refers to deterministic variant
parity, not original MCMC.
