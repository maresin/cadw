## §2. API notes (for promote v0.9.223)

**Prediction semantics (LightGBM-style, not sklearn):**
- `predict(X)` for regression -> float predictions
- `predict(X)` for binary classification (logistic/focal) -> P(y=1)
- `predict_proba(X)` for binary classification -> P(y=1) (1D, not (n,2))
- `predict(X)` for multiclass -> int class labels (via CADWBoostMulticlass)
- `predict_proba(X)` for multiclass -> (n, K) softmax probabilities

**Promotion must decide:** keep LightGBM convention OR add sklearn-style
`(n, 2)` output via new `predict_proba_2d` method. Recommend **keep
LightGBM-style** (1D for binary) as primary; document clearly.

**Missing API** (needs to be added in v0.9.223 wire):
- `predict_batched(df)` — df path for predict (currently only `fit_df`)
- `state_nbytes()` — exists, but formula needs documenting in YAML
- `feature_importance(...)` — exists on `CADWBoost`
- `save_json`/`load_json` — exist in `serialize.py` as free funcs;
  need class methods (`CADWBoost.save_json(path)` / `load_json(path)`)
