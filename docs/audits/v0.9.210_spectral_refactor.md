## §1. Over-eager claim in v0.9.209-b

v0.9.209-b set `ooc_status: achievable` for 3 SpectralClustering cards
with `ooc_alternative` claiming:
> "Sparse affinity path already implemented: graph_laplacian_sparse
>  (v0.9.203) + eigsh_topk (sparse branch) for n>2000; dense n<=2000
>  path is exact. Caller picks by input density. OOC in nnz via sparse
>  Laplacian (state O(n*k))."

**This was misleading.** Sparse = Laplacian/ARPACK, NOT X or embedding:
- `X` was materialized O(n*d) (line 70-77 of pre-v0.9.210 code).
- `W` = affinity (nnz = n*k_nnz) intrinsic.
- `embedding` = (n, k) intrinsic.
- ARPACK Lanczos matvec = O(n*k) per iteration intrinsic.

**Diagnosis (P4/P5 probes):**
- v0.9.209 `fit_spectral_clustering` already used `knn_query_stream`
  internally for W build, but materialized X first via `np.vstack`.
- `bounded_by_domain {n: 1e6}` was honest (X materialization blocker).
- `n_scalability: linear` was honest (W + embedding = O(n)).

The claim "sparse path already implemented, flip bs=true" was over-eager:
W + embedding remain O(n) regardless of Laplacian sparsity.

## §2. v0.9.210-a refactor (honest improvement)

**What changed:**
- X **streamed** via `knn_query_stream` for `affinity="nearest_neighbors"`
  (fresh `_fresh_x_iter` per call → no `np.vstack` of X_parts).
  X (n*d) no longer in RAM.
- `rows/cols/vals` **preallocated** `np.empty` + vectorized
  (`np.repeat` + `ravel`) — replaces Python `list.append` loop.
- `SlowOperationWarning` (AP22) at est compute > 60s.
- k_eff = `n_neighbors` (self is idx[:,0]; no explicit self-loop;
  `W.setdiag(1.0)` no-op) — matches sklearn `kneighbors_graph(X, k,
  include_self=True)` = 15 nnz/row.
- rbf affinity: X still materialized (`pairwise_kernel` intrinsic).

**What did NOT change (honest — still intrinsic):**
- W (n*k_nnz) — required by ARPACK Lanczos matvec.
- embedding (n, k) — required by kmeans.
- `bounded_by_domain {n: 1e6}` — kept.
- `bounded_state: false` — kept.
- `n_scalability: linear` — kept.

**Evidence (P6/P7):**
- W bit-identical to sklearn: max abs diff = 0.0.
- nnz parity: 4364 = 4364 (n=200, k=15).
- ARI on `make_blobs` (existing 12 tests): all pass.
- Speedup: n=1000 ~0.39s (was 0.98s, 2.5x); n=5000 ~4-5s (was ~23s).

## §3. Honest revert (v0.9.210-c)

**`ooc_status: achievable → debt`** for 3 cards. Because exact spectral
clustering on arbitrary n is O(n*k) intrinsic (W + embedding + ARPACK).
Only approximation can reduce n.

**`ooc_alternative`** (concrete):
1. Landmark n_b<=5000 + out-of-sample transform via kNN.
2. Nystroem kernel approx + PCA chain (precedent KernelPCA v0.9.202).
3. MiniBatchKMeans on raw features for approximate clustering.

**`ooc_target_version: null`** (permanent debt; approximation is a
different algorithm, not a streaming variant).

## §5. Lessons

1. **"Primitive implemented" ≠ "model OOC".** Sparse Laplacian + eigsh
   remove L-dense, but W + embedding + ARPACK matvec are still O(n).
   Over-eager achievable claim missed this.
2. **Probe first, claim later.** v0.9.209-b was based on 1-line summary
   of v0.9.203 primitives, not on reading `fit_spectral_clustering`
   dispatch logic.
3. **Speedup ≠ OOC.** 2.5-5x faster is real (X streaming + preallocate
   fixed), but state still O(n*k). Both can be true simultaneously:
   `ooc_status: debt` + 5x speedup.
4. **W bit-identical is the test.** P6/P7 gave hard evidence before
   any claim change. `test_W_bit_identical_sklearn` now guards regression.
5. **Quick win выбор** — Spectral sparse flip looked like quick win
   (primitives ready), но required refactor + status revert. Not a quick
   win. Проверять depth before labeling.
