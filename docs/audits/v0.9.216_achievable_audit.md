## §2. Intrinsic / honest permanent (3) — do NOT flip

These are structurally O(n) or O(n²); no streaming refactor possible
without algorithm change (per DEC-075, ROADMAP §"Do not re-solve").

### §2.1 CoxPH

- **state:** `coef_ (d) + baseline_t_ (n_events) + baseline_h_ (n_events) + cov (d² if closed) + 256`
- **why intrinsic:** baseline hazard requires one row per distinct event
  time (Breslow estimator). `n_events ≤ n` (events only); at n=1e6 with
  30% censoring, n_events ≈ 7e5 → ~11 MB. Statistically stable up to
  n≤1e6 (v0.9.97 do-not-re-solve).
- **fit/predict OOC:** ✅ via `external_sort` (v0.9.93) +
  `_breslow_streaming` (v0.9.206). Only **state** is O(n_events).
- **card action:** keep `bounded_by_domain {axis: n, bound: 1e6}`;
  change `ooc_status: achievable → debt` (permanent, no plan) + set
  `ooc_alternative: "Permanent: Breslow baseline requires O(n_events);
  statistical limit n≤1e6 (v0.9.97). Fit/predict are OOC."` — **recommend**
  but **not in v0.9.216** (out of scope; needs separate card decision).

### §2.2 KernelPCA

- **state:** `X_fit (n×d) + K_fit_rows (n) + eigvecs (n×k) + eigvals` — O(n)
- **why intrinsic:** exact kernel PCA needs full kernel matrix K (n×n_fit).
  `n≤1e4` intrinsic bound (800 MB K + 800 MB eigh copy). Nystroem
  approximation (v0.9.202) is a **separate class** (`fit_nystroem_kernel_map`),
  not a refactor.
- **card action:** keep `bounded_by_domain {axis: n, bound: 1e4}`;
  `ooc_alternative` already documents Nystroem. **No change needed.**

### §2.3 SpectralBiclustering

- **state:** `row_labels (r) + col_labels (c) + rows_ind/columns_ind + A (r*c) + A_norm (r*c) + U (r*n_sv)`
- **why not flip yet:** `A = np.vstack(A_parts)` materializes full
  matrix (P24f line 80-88). `_project_and_cluster(A, ...)` requires
  full A (sklearn parity). `U` from `svd_topk` collected via
  `np.vstack` (P24f line 134-143) — **defeats svd_topk OOC**.
- **refactor plan (v0.9.217):** 2-pass normalize (Reduce) +
  stream A_norm to svd_topk + stream U into Z_df + chunked
  `_project_and_cluster` (precedent Coclustering v0.9.207 pass 3-4) +
  SpillArray labels. Target: `bounded_by_window {gram_dim: 1e4}`,
  drop `bounded_by_domain {r*c: 1e9}`.
- **card action (v0.9.216):** no change (keep achievable). Refactor
  scheduled v0.9.217 (see ROADMAP).
