## §2. Actions taken

### v0.9.206-a (card-fix ×2)

1. **`knn_query_stream`**: `layer: leaf -> batch`, `bs: false -> true`.
   - Code streams `X_iter` (linalg.py:66-107); state O(n_q·k), independent of n_x.
   - `check_state(n_q*k*8*2)` + `check_state(n_q*chunk*8)` present.
   - Consumers LOF/KNNImputer `verified+bs=true` — no regression (G22 skips
     `knn_query_stream`: not `^_name`, per `test_G22` line 1327).

2. **`_baseline_hazard_streaming`**: `layer: batch -> leaf`, `bs: true -> false`,
   `+ ib {axis: n_events, bound: 1e6}`.
   - `ram_formula "2*n_events*f64"` grows with n_events (all-uncensored -> n) —
     `bs=true` was dishonest (fake batch-layer).
   - Caller guard in `fit_coxph` (coxph.py:601,648: `check_state(2*n_events*8)`).
   - CoxPH card: `bs=false, bounded_by_domain {n: 1e6}` (unchanged; not
     affected — G22 only checks verified + bs=true models).

### v0.9.206-b (code-fix ×1)

3. **`_breslow_streaming`**: add `mg.check_state(2*d*d*8 + 2*d*8 + 256,
   "coxph.breslow_streaming.state")` before `np.zeros((d,d))`.
   - G2 violation: allocations at coxph.py:11-16 without guard.
   - Silent OOM risk: `d=1e4` -> state 1.6 GB; at current budget -> guard now
     fires before alloc.
   - Behavioral: `test_breslow_streaming_guard_fires` (d=100, 0.001 MB ->
     MemoryLimitExceeded), `test_breslow_streaming_passes_at_adequate_guard`
     (d=20, 100 MB -> OK).

### v0.9.206-c (G23 gate + this audit doc)

4. **G23 static** (`test_G23_batch_primitive_no_n_in_ram_formula`):
   for each `layer: batch + bs: true`, `ram_formula` must not contain
   n-sized identifiers (n, N, n_events, n_rows, n_total, n_x, n_groups,
   n_samples, n_train, n_test, n_obs, n_mem) as standalone terms.
   Whitelisted: batch, row_size, d, k, K, p, q, s, W_eff, chunk, min_size,
   k_arms, n_q, n_y, n_features, nnz, state_bytes, n_estimators.

5. **G23 behavioral placeholder** (`_G23_FIXTURES = {}`): empty whitelist
   (v0.9.206 initial). Individual primitives already covered by CW tests
   in their verification suites (`test_linalg_svd::test_ooc_in_n_rows`,
   `test_lof_verification::test_state_constant_in_n`, etc.).
