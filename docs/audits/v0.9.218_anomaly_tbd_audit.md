## §2. Detailed verdicts

### §2.1 Sub-PCA — achievable

**P35 evidence:**
- `output='memory'` (no 'auto'); signature: `contamination: float = 0.1` (не Optional)
- `SubPCAResult.decision_scores (n) + labels (n) + components (k·w) + mean (w)`
- `spill=True` (SpillArray already imported), `iter_batches=True`
- `_map_max` (L121/L126): score per window → map to n
- No training (PCA via covariance on window chunks — like T²+Q Welford)

**Achievable path (precedent Hampel v0.9.217 + T²+Q intrinsic alternative):**
1. `contamination: float | None = 0.1`; if `None` → `threshold=n_sigma` (no percentile)
2. `output='memory' | 'auto' | 'disk'`
3. `output='auto'`: SpillArray for `decision_scores`, `labels`, `window_scores`
4. 2-pass streaming: window scores → SpillArray; `_map_max(window_scores, w, n)` → decision (O(n·w) transient, O(n) output)
5. contamination requires `output='memory'` (percentile needs full window_scores)
6. `SubPCAResult.is_spilled` + `state_nbytes() = 256` (spilled) / O(n)+O(k·w) (memory)

**Target:** v0.9.219.

**Cross-ref:** same pattern as T²+Q intrinsic alternative (v0.9.218-b
ooc_alternative); Sub-PCA simpler because single window score (no
t2/q/combined triplet).

### §2.2 BOCPD — achievable (best ROI)

**P35 evidence:**
- `contamination: float | None = None` — **уже Optional!** No API change for this
- `posterior_keep: int = 64` — bounded posterior state (O(64 · max_run))
- `max_run: int | None = None` — bounded run length
- `R_hist (keep, max_run+1)` — O(64 · max_run), not O(n)
- Output: `anomaly_score (n)`, `argmax_run (n)`, `changepoints (k)` — O(n)
- **Already OOC по state** (rolling posterior, v0.9.87-fix1c)

**Achievable path:**
1. `output: str = 'auto'` — new param
2. SpillArray for `anomaly_score`, `argmax_run`, `changepoints`
3. `BOCPDResult.is_spilled` + `state_nbytes()` already O(1)-in-n
4. Existing `posterior_keep` already bounds posterior state

**Target:** v0.9.219 (easy — already OOC by state; add output param only).

### §2.3 KShapeAD — achievable

**P35 evidence:**
- `output='memory'`, `spill=True`, `iter_batches=True`
- `KShapeResult`: `decision_scores (n) + labels (n) + centroids (k·w) + ...`
- Training: kmeans over shapes (iterative, O(n·k·w) per iter)
- `scores = np.full(n, -np.inf)` at L261 (map from window_scores)
- `labels = np.empty(n_w)` at L281

**Achievable path:** same as Sub-PCA (2-pass window_scores → decision map + SpillArray).
Training fit transient: check if `X = np.vstack(chunks)` (full) or iterative on chunks. P35 shows `spill=True` — likely already partial.

**Target:** v0.9.220.

### §2.4 S2G — achievable

**P35 evidence:**
- `output='memory'`, `spill=True`, `iter_batches=True`
- `S2GResult`: `decision_scores (n) + labels (n) + graph (n_nodes²) + embedding + ...`
- `W (n_nodes, n_nodes)` at L296 — bounded by `n_nodes` hyperparameter
- `M2 (d_z, d_z)` at L192 — Welford O(d_z²)
- `cumsum (n_w, 1)` at L105 — bounded accumulator

**Achievable path:** same as Sub-PCA. `n_nodes` bounds graph state; `d_z` bounded; only `decision_scores + labels` O(n) → SpillArray.

**Target:** v0.9.220.

### §2.5 EIF — debt (intrinsic)

**P35 evidence:**
- No `output` param (like KMeansAD)
- No spill (`spill=False`)
- Training: per-tree extended isolation forest, `paths = np.zeros(n)` at L205, `window_scores = np.empty(n_w)` at L555
- Training on full window matrix (n_w × w) — like Autoencoder

**Verdict:** debt. Same class as Autoencoder/PMA (v0.9.217-b). Would
require full redesign with reservoir training + streaming inference.

**ooc_alternative:** "Permanent: training per-tree EIF over full window
matrix (n_w × w); no spill API. bounded_by_domain n<=1e6."

**Action:** YAML flip achievable → debt (v0.9.218-c same patch).

### §2.6 KMeansAD — debt (intrinsic)

**P35 evidence:**
- No `output` param, no spill
- `reservoir=True` — training on reservoir subsample (S = max_samples)
- Training kmeans (L101-102 `labels = np.zeros(n)`, `dists_sq = np.zeros((n, k))` — actually full n)

**Verdict:** debt. Training uses full window matrix for distance computations (L102 `dists_sq = np.zeros((n, k))` — O(n·k)); reservoir только для init sample. Similar to Autoencoder.

**ooc_alternative:** "Permanent: kmeans training over full window
matrix (dists_sq O(n·k)); reservoir only for init. bounded_by_domain
n<=1e6."

**Action:** YAML flip achievable → debt (v0.9.218-c same patch).

## §10. v0.9.220 correction (post-implementation probe)

optimistic for 3 of 4 achievable models:

**Reclassified achievable -> debt (intrinsic):**

  np.percentile(decision_scores, 100*(1-c)) requires full scores array;
  _map_max also requires full window_scores.
- **KShapeAD**: kshape.py L589 np.percentile(decision_scores, ...);
  same class.
- **S2G**: s2g.py L548 np.percentile(ts_scores, ...); same class.

**BOCPD** was correctly achievable (v0.9.219-b): contamination already
Optional[float]=None -> threshold 0.5 fixed, no percentile.

**Updated anomaly final (14 cards / 13 unique):**
- achieved: 4 cards (Hampel, CUSUM, ZMS, BOCPD)
- achievable: 0 cards
- debt: 10 cards (9 unique; DWT-MLEAD, Autoencoder x2 dup,
  PatchMemoryAD, T²+Q, EIF x2 dup, KMeansAD x2 dup, Sub-PCA x2 dup,
  KShapeAD, S2G)

Note: counts are per-card; Sub-PCA appears in both D3.1 + D3.3
(duplicate classification cards).

**Lesson:** "already OOC-by-state" (BOCPD) vs "OOC-by-state but
threshold requires full array via default contamination" (Sub-PCA/
KShapeAD/S2G) is a 10x effort difference. Audit v0.9.218-c conflated
"has output param" with "achievable" — real test = read threshold
logic + contamination default.

**Achievable path (v0.9.221+, breaking change):** contamination:
float|None = 0.1 -> if None threshold=n_sigma (default 3.0); output=
'auto' + SpillArray. Requires DEC approval for default UX break.
